# STARFALL: Expedition Zero

لعبة بقاء فضائية من منظور علوي، مبنية بمشاهد ورسوم إجرائية داخل Godot، بلا أصول خارجية أو إضافات مطلوبة. المشروع موجّه للعب بالعرض على الهاتف.

## المتطلبات
- Godot 4.7.x (المشروع مضبوط على خط 4.7).
- لا توجد ملفات أصول تحتاج تنزيلًا.
- Renderer: Compatibility / GL Compatibility لزيادة فرص العمل على أجهزة أندرويد.

## تشغيل المشروع
1. فك ضغط الملف بالكامل.
2. افتح Godot Editor.
3. اختر Import أو Scan، ثم حدّد مجلد المشروع الذي يحتوي `project.godot`.
4. افتح `scenes/Main.tscn` أو اضغط تشغيل المشروع.
5. اترك الهاتف بوضع أفقي (Landscape). المشروع يطلب الاتجاه الأفقي من إعدادات العرض.

## عناصر اللعب
- عالم إجرائي كبير مع موارد: خردة، بلورات، ألياف، غاز، سبائك وكتل حيوية.
- موجات أعداء بثلاثة أنواع عادية وزعيم Titan كل ثلاث موجات.
- إطلاق نار تلقائي، مقذوفات، أضرار، خبرة، مستويات ونقاط مهارات.
- شجرة مهارات من تسعة فروع: صحة، سرعة، جمع، ضرر، علاج، هندسة، سرعة إطلاق، درون، وإنقاذ.
- التصنيع: إسعاف، ذخيرة معززة، برج آلي، حاجز، مصفاة، قنبلة، ترقية سلاح وبدلة.
- بناء منشآت، مهام، مكافآت، مخزون، خريطة مصغرة، حفظ محلي.
- تحكم باللمس وأزرار واجهة، مع اختصارات لوحة مفاتيح عند الاختبار على الكمبيوتر.

## التحكم
- لمس يسار الشاشة وسحب: الحركة.
- لمس الجهة اليمنى: توجيه/إطلاق.
- زر جمع: التقاط الموارد القريبة.
- إسعاف / قنبلة: استخدام العناصر.
- برج / حاجز / مصفاة: بناء فوري أمام اللاعب.
- المهارات / التصنيع / المهام / الحقيبة: فتح القوائم.
- `WASD` أو الأسهم: الحركة عند وجود لوحة مفاتيح.
- `E`: جمع، `H`: إسعاف، `G`: قنبلة، `I`: حقيبة، `K`: مهارات، `C`: تصنيع، `J`: مهام، `F5`: حفظ، `Esc`: إيقاف مؤقت.

## الحفظ
يحفظ التقدم إلى `user://starfall_save.json` على الجهاز الذي يشغّل اللعبة. زر حفظ التقدم موجود في قائمة الإيقاف المؤقت.

## تصدير أندرويد
لتصدير APK من محرر Godot تحتاج إعداد Android build template وAndroid SDK/JDK متوافقين. محرر Godot على أندرويد قد لا يوفر مسار تصدير APK كاملًا على كل جهاز. يمكن تجربة المشروع وتشغيله داخل المحرر أولًا، ثم إعداد التصدير بحسب قدرات الجهاز.

## ملاحظات الاختبار
المشروع يعتمد رسومات إجرائية لتجنب حزم أصول كبيرة، وليس 100MB من الحشو. ملف أكبر لا يعني لعبة أفضل؛ المحتوى والأنظمة أهم من وزن الأرشيف.
تم فحص سلامة ZIP وبنية الملفات آليًا. لم يتوفر محرك Godot فعلي ضمن بيئة الإنشاء لإجراء تشغيل/اختبار تكاملي؛ لذا شغّل المشروع في المحرك، وأرسل أي خطأ ظاهر لنصلحه.
