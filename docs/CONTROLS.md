# Controls / التحكم
- Left side touch and drag: move.
- Right side touch: aim/fire.
- Collect: gather nearby resource nodes and drops.
- Medkit: restore health.
- Grenade: damage nearby enemies.
- Turret / Wall / Refinery: build nearby.
- Inventory, Skills, Crafting, Quests: open systems.
- Keyboard: WASD/arrows, E collect, H medkit, G grenade, I inventory, K skills, C craft, J quests, F5 save, Esc pause.
