# Roadmap
The delivered build includes the core loop and several connected systems. Potential next milestones:
1. Split the main script into reusable Player, Enemy, ResourceNode, Building and UI scenes.
2. Add sound and music, sprite sheets, animation, and localization resources.
3. Add additional biomes and a mission/event director.
4. Add equipment rarity, weapon selection, status effects and boss phases.
5. Add controller remapping and Android export presets.
6. Run the project in Godot 4.7.x and fix any runtime/parser findings from the actual engine.
